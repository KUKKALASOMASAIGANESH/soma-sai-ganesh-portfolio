# Soma Sai Ganesh — React Portfolio

A futuristic, responsive developer portfolio built with React, Vite, Tailwind CSS, Motion, Three.js and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

The project includes a GitHub Actions workflow under `.github/workflows/deploy.yml` for GitHub Pages.

Before deploying, set the Vite `base` in `vite.config.js` to your repository name if you are using a project-page URL. For a `USERNAME.github.io` repository, `/` is correct.
